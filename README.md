# Il Guardiano — gestionale ingressi Halloween

Web app statica per gestire gli ingressi di una serata: lista ospiti, scansione QR,
capienza e incassi. Funziona offline dopo la prima apertura.

Tutti i dati restano nel browser del dispositivo che la usa: qui non c'è nessun server
e nessuna lista ospiti, solo il codice dell'app.
